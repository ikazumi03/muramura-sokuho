むらむら速報｜公開・運用セットアップ手順


FANZA（DMM）の成人向けコンテンツの選び方を案内する、18歳以上向けの情報サイトです。
静的HTMLで構成され、広告はDMMアフィリエイト（アダルト向け区分）のみを使います。
現時点では広告コードは未設置で、各ページの広告枠は「広告枠（準備中）」のプレースホルダです。


1. GitHubで新規リポジトリを作成します（既存の affiliate-auto-site / otona-deai-guide とは混ぜない）。
このフォルダの中身をリポジトリの最上位にアップロードします（index.html、assets、.github がルートに来る形）。
2. about.html の運営者情報と contact.html の連絡先にある「（公開前に記入）」を実際の情報へ変更します。
3. Cloudflare Pagesで公開します。
Workers & Pages → アプリケーションを作成 → Pages → Gitリポジトリからインポート。
Production branch: main / Framework preset: None / Build command: 空欄 / Build output directory:.（ルート）
公開URLが muramura-sokuho.pages.dev 以外になった場合は、sitemap.xml、robots.txt、
.github/workflows/weekly-audit.yml の SITE_URL を実際のURLへ差し替えます。
4. DMMアフィリエイトに登録します（登録は本人が行います）。
- DMM会員登録（無料）→ affiliate.dmm.com で参加申請
- 基本アフィリエイトID（半角英数字12文字以内・後から変更不可）、サイト名「むらむら速報」、公開URLを登録
- サイトの登録区分は「アダルト向け」を選ぶ
- 審査は通常約3営業日。初回に申請できるのは1サイトのみ
※中身の薄い新規サイトは審査に落ちやすいため、まず本サイトを10ページ前後の実コンテンツで公開してから申請する順番にしています。
5. 承認されたら、管理画面で振込口座を登録します。
6. 広告コードの設置（承認後）：
- 商品ページや管理画面で発行される正規のアフィリエイトリンク／バナーコードを改変せずに使います。
- 各ページの「広告枠（準備中）」プレースホルダを、公式コードに置き換えます。
- 広告を入れたページには「広告」「PR」の表記があることを確認します（各ページの注意書きと policy.html に方針を明記済み）。
7. 週次点検：.github/workflows/weekly-audit.yml が毎週月曜08:35（日本時間）頃に ops/site_audit.py を実行します。
結果は Actions の Artifacts（weekly-site-audit）と reports/latest.md に残ります。手動実行も可能です。


- 銀行口座・本人確認などの個人情報は、GitHubやチャットに貼らず、DMMの管理画面へ直接入力してください。
- A8.net などアダルト規約で禁止されるASPの広告を、このサイトに混在させないでください。
- 自前の露骨な画像・性描写は掲載しません。商品画像は承認後に使える公式広告素材のみです。
- 体験談・口コミ・ランキングの捏造はしません。料金は公式確認日を明記する運用です。
- 収益や検索順位は保証されません。
